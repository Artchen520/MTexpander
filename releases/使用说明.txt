 代码修补 v4.5.2 —— MT管理器插件
 插件ID：com.artchen520.expander
════════════════════════════════════════

【升级说明】
v3.0 直接覆盖安装（v2 设置自动迁移：原自定义库 → 「通用」分组，
首次运行自动生成可编辑的「内置」分组文件）。

────────────────────────────────────────
一、缩写展开
────────────────────────────────────────
▶ 光标模式：输入缩写后光标停在缩写词后面，
  点底部工具栏「展开片段」。
▶ 选中模式：选中缩写词，浮动菜单点「展开片段」。
▶ 只匹配「适用当前文件类型且已启用」的分组；
  缩写存在但类型不符会提示所属分组和适用范围。

▶ 全部展开（v4.5.2）：点底部工具栏「分组」打开面板，
  点面板底部「全部展开」按钮，
  一键展开当前文件里所有已用到的缩写：
   · 弹预览：每个缩写 × 出现次数，注释/字符串里
     的出现数单独标出；与 Java 关键字撞名的条目加 ⚠
   · 「展开」= 默认模式，跳过注释和字符串里的命中
   · 「全部展开(含注释)」= 连注释/字符串一起换
   · 只替换缩写词本身；多行模板自动对齐该行缩进；
     $S$ 批量模式下删除，光标停在第一处展开位置
   · 适合"先写一堆缩写、再统一展开"的写法；
     已带参数的缩写（如 logd(x)）展开后需自行清理残参

────────────────────────────────────────
二、批量注释（对齐 + 跟随类型）
────────────────────────────────────────
选中多行 → 浮动菜单「批量注释」→ 再点一次取消。

▶ 对齐：所有注释符插在块内最小缩进列，同一列整齐排列：
     // int a;
     // if (x) {
     // }
▶ 取消注释同时兼容对齐式和 v2 旧式（各行缩进）。
▶ 注释符跟随文件类型：
   java/kt/c/cpp/js/ts/go/cs/php/swift → //
   xml/html/htm/svg                    → <!-- -->
   py/rb/pl/sh/bash/smali/yaml/toml…   → #
   sql/lua                             → --
   其他/无扩展名                        → //

────────────────────────────────────────
三、环绕包裹
────────────────────────────────────────
选中一段代码 → 浮动菜单「环绕包裹」→ 模板列表
（按当前文件类型过滤）。选中内容自动加深缩进、
保留内部相对缩进，光标停在条件位置。

────────────────────────────────────────
四、分组系统（核心新特性）
────────────────────────────────────────
▶ 概念：一个分组 = 一个 .txt 库文件（缩写组、环绕组独立）。
  组内每条可限定适用的文件类型。

▶ 编辑器内开关：底部工具栏「分组」按钮（或顶部编辑菜单「分组开关」）打开面板，
  勾选即生效，不用退出编辑器：
   [x] 内置 · 12 条 · 所有文件
   [x] 通用 · 3 条 · 所有文件
   [ ] XML 组 · 5 条 · xml
  默认为临时切换（本次有效）；勾选面板底部
  「持久记住」后立即固化当前状态，重启仍生效；
  设置页可改「开关面板默认持久」。

▶ 分组文件格式（设置页点分组名编辑）：
   #适用：java,smali          ← 组默认范围（省略=所有文件）
   sout = System.out.println($0$); @java
   fori = for (...) {\n    \n} @          ← @空 = 强制通用
   logd = Log.d(TAG, $0$); @java,smali    ← 单条限定
   /* */ = /* $S$ */$0$                   ← 环绕模板必须含 $S$
  · 行尾 @java,smali = 单条限定；@（空）=强制通用；无 @ =组默认
  · 范围写扩展名（java）或完整文件名（.gitignore、Makefile）
  · $0$ = 光标位置；$S$ = 选中内容；\n = 换行；# = 注释

▶ 新建/删除分组在设置页操作；
  「内置」组可直接改，删除即停用全部内置条目。

▶ 重名规则：允许不同分组存在同名条目（保存时提醒），
  按分组名称排序依次匹配，先命中先生效。

▶ 匹配顺序 = 设置页分组显示顺序（名称排序）。
  关闭分组（v4.4 细化）：组内有限定范围的条目停用，
  通用条目（无范围限制）默认继续可用（与通用型无区别）；
  面板/设置页的「停用分组时，同时停用其中的通用条目」
  开启后，整组彻底停用（含通用条目）。

────────────────────────────────────────
五、排错
────────────────────────────────────────
· 升级后无变化 → 重启 MT；插件管理确认已启用。
· 底部工具栏应有「展开片段」「分组」按钮；
  「全部展开」在「分组」面板底部。功能按钮需在 MT 编辑器里手动调出。
· 环绕列表少了条目 → 检查其分组是否被关、$S$ 是否存在、
  适用范围是否包含当前文件类型。
· 其他问题把报错信息发给开发者。
